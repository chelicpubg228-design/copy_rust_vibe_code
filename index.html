🌟 Особенности проекта

🧩 Изолированное ядро
Игровая логика (src/core/, класс cr::Game) полностью отделена от UI — можно тестировать юнит-тестами.
🖼️ Графический фронтенд
SFML 3: генерация острова, лагерь, деревья, руда, животные, день/ночь, HUD, хотбар, инвентарь, крафт, миникарта, зум и F11-фullscreen.
💾 Консольный режим
Полноценный CLI-фронтенд (src/console_frontend/) для серверов и терминалов без графики.
🧪 Автотесты
Набор тестов CTest (tests/test_core.cpp) — ядро игры проверяется автоматически.
💾 Сохранения JSON v2
savegame.json, автосохранение каждые 60 секунд и при выходе, слоты F5/F9.
🌐 RU / EN
Система локализации (src/ui/Localization.*) и переключение языка консольной командой lang ru|en.

🧪 Интерактивный эмулятор выживания (мини-демо)

🛠️ Сборка

Требования

Windows 10/11, Visual Studio 2022 (MSVC x64), CMake 3.20+, vcpkg (sfml 3.x, nlohmann-json).

Команды

cd "D:\rust_ccop\copy_rust\v6.0 - GUI"

cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_TOOLCHAIN_FILE=D:/for_vv/vcpkg/scripts/buildsystems/vcpkg.cmake

cmake --build build --config Release

:: Графический режим
.\build\Release\real_copy_rust.exe

:: Консольный режим
.\build\Release\copy_rust_console.exe

:: Тесты
ctest --test-dir build -C Release --output-on-failure
