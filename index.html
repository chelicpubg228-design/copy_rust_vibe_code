обзор

Остров живёт по своим правилам

Ядро симуляции отделено от интерфейсов и покрыто тестами: один и тот же мир работает и в графическом окне, и в консоли. Ни один кадр не зависит от UI-логики.

🧩
Изолированное ядро

cr::Game и src/core/ не знают ни про SFML, ни про консоль. Логика, баланс и события — в одном месте.

🗺️
Процедурный мир

Сидируемая генерация: деревья трёх размеров, камень, железо, сера, ткань, ягоды и четыре вида зверей.

🌓
Цикл суток

День длится 360 секунд. Ночью падает видимость, а волки становятся заметно смелее — держитесь ближе к костру.

🪓
Инструменты и износ

Четыре слота хотбара, прочность у каждого инструмента, ремонт и замена. Камень → железо → выживание.

💾
Автосохранение

JSON формата v2, автосейв каждые 60 секунд и при выходе, ручные слоты на F5 / F9.

🧪
Тесты CTest

Модульные проверки ядра: показатели, крафт, урон, инвентарь. Сборка не считается готовой, пока тесты красные.

сборка

Собрать из исходников

Windows 10/11 · Visual Studio 2022 (MSVC x64) · CMake 3.20+ · vcpkg: sfml 3.x и nlohmann-json 3.12+.

  1. Скачайте v6.0_gui_full.zip и распакуйте в отдельную папку — DLL уже внутри.
  2. Запустите real_copy_rust.exe (графика) или copy_rust_console.exe (консоль).
  3. Сохранение появится рядом с exe. SmartScreen: «Подробнее → Выполнить в любом случае».
# клонирование
git clone https://github.com/chelicpubg228-design/copy_rust_vibe_code.git
cd copy_rust_vibe_code

# конфигурация (подставьте путь к своему vcpkg)
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_TOOLCHAIN_FILE=D:/for_vv/vcpkg/scripts/buildsystems/vcpkg.cmake

# Release-сборка и тесты
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure

# запуск
.\build\Release\real_copy_rust.exe
.\build\Release\copy_rust_console.exe
