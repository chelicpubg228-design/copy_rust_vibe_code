copy_rust_vibe_code

// Copy Rust 2D · v6.0 — GUI Edition 🌲⚡

Графическая игра на выживание на C++20 и SFML 3. Исследуй сгенерированный остров, добывай ресурсы, крафти инструменты, охоться на зверей и переживай ночи у костра. Есть и консольный режим без графики.

Скачать v6.0 GUI Консольная версия Исходный код

Суть игры

Ты высаживаешься на сгенерированный остров с каменным топором и факелом. Днём исследуешь мир: вокруг деревья, руда, ягодные кусты и звери. Ночью темнеет — возвращайся к лагерю и костру, чтобы отдохнуть и восстановить силы. Любое действие тратит еду, воду и энергию, поэтому следи за показателями HUD: если какой-то кончится, персонаж умирает, и запускаешься заново.

🌲 ИсследуйОстров генерируется сам: деревья, камень, железо, ягоды, звери. Двигайся клавишами или ходи кликами мыши.
⛏️ Добывай и крафтиХотбар с инструментами (клавиши 1–4), меню крафта под C, инвентарь под I.
🔥 ВыживайДень/ночь, голод, жажда и энергия. Прятки, бегство и сон у костра. F5 — сохранить, F9 — загрузить.

Показатели выживания

ПоказательСтартЧто происходит
Здоровье (HP)100Падает от ран и холода. При 0 — смерть и возрождение у лагеря.
Еда100Тратится на любые действия. Восстанавливается ягодами и едой (F).
Вода100Тратится на любые действия. Следи, чтобы не кончилась.

Время сутокутроСменяется динамически: ночью видно хуже и опаснее.

Игра сохраняется сама каждые 60 секунд и при выходе (JSON v2, файл savegame.json рядом с .exe). Смерть сбрасывает позицию — но развёрнутый лагерь остаётся.

Консольный режим (CLI)

В комплекте есть консольная версия copy_rust_console.exe — для слабых ПК и серверов. Команды:

status, lookgo n|s|e|wgather, attack
inv, craft, tool <1-4>cycle, eat, restequip / unequip
save, loadlang ru|enhelp, quit

Как запустить

Скачай v6.0_gui.exe (или консольную версию), положи в отдельную папку и запусти. Файл сохранения появится рядом с .exe. Если Windows покажет SmartScreen — «Подробнее» → «Выполнить в любом случае».

Сборка из исходников

Нужны: Windows 10/11, Visual Studio 2022 (MSVC x64), CMake 3.20+ и vcpkg с пакетами sfml (3.x) и nlohmann-json.

git clone https://github.com/chelicpubg228-design/copy_rust_vibe_code.git
cd copy_rust_vibe_code

cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_TOOLCHAIN_FILE=D:/for_vv/vcpkg/scripts/buildsystems/vcpkg.cmake

cmake --build build --config Release

:: графическая версия
.\build\Release\real_copy_rust.exe
:: консольная версия
.\build\Release\copy_rust_console.exe

:: тесты ядра
ctest --test-dir build -C Release --output-on-failure
