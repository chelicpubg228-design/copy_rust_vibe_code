Обзор проекта

Ядро игры отделено от интерфейсов и покрыто автотестами — двадцать лет C++ не проходят зря.

🧩
Изолированное ядро

Игровая логика (cr::Game, src/core/) не зависит ни от SFML, ни от консоли. Один код — два фронтенда.

🗺️
Процедурный мир

Генерация острова: деревья, рудные жилы, ягодные кусты, звери. Координатная система мира с тремя зонами удалённости.

🌓
День и ночь

Динамический цикл суток. Ночью видимость падает — возвращайтесь к лагерю и костру.

🪓
Добыча и крафт

Хотбар из 4 слотов, прочность инструментов, рецепты: каменный топор, железный топор, кирка, броня.

💾
Автосохранение

JSON v2 (savegame.json), автосейв каждые 60 секунд и при выходе, ручные слоты F5/F9.

🧪
Тесты CTest

Модульные тесты ядра (tests/test_core.cpp): показатели, крафт, бой. Запускаются одной командой.

Запуск

  1. Скачайте v6.0_gui_full.zip и распакуйте в отдельную папку.
  2. Запустите real_copy_rust.exe (графика) или copy_rust_console.exe (консоль).
  3. Файл сохранения появится рядом с exe. При предупреждении SmartScreen: «Подробнее → Выполнить в любом случае».

Сборка из исходников

Windows 10/11 · Visual Studio 2022 (MSVC x64) · CMake 3.20+ · vcpkg: sfml 3.x, nlohmann-json 3.12+

# клонирование
git clone https://github.com/chelicpubg228-design/copy_rust_vibe_code.git
cd copy_rust_vibe_code

# генерация сборки (укажите toolchain вашего vcpkg)
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_TOOLCHAIN_FILE=D:/for_vv/vcpkg/scripts/buildsystems/vcpkg.cmake

# компиляция Release
cmake --build build --config Release

# запуск и тесты
.\build\Release\real_copy_rust.exe
.\build\Release\copy_rust_console.exe
ctest --test-dir build -C Release --output-on-failure
