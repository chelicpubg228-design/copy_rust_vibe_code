Переработанная версия 2D симулятора выживания **Copy Rust** на **C++20** и **SFML 3**.  
Проект включает изоляцию игрового ядра от графического интерфейса, консольный режим, веб-презентацию (`index.html`), автоматические тесты CTest и гибкую систему сохранения состояния мира.

---

## 🌟 Основные особенности

- **Изолированное игровое ядро (`src/core/`)**: Логика игры полностью очищена от UI-зависимостей (`cr::Game`), что позволяет проводить модульное тестирование.
- **Графический 2D-фронтенд (SFML 3)**:
  - Генерация острова, лагерь, деревья, руда, животные.
  - Динамическая смена дня и ночи.
  - HUD, интерактивный хотбар, инвентарь, экран крафта и миникарта.
  - Поддержка зума, полноэкранного режима (F11) и подсказок (F1).
- **Консольный фронтенд (`src/console_frontend/`)**: Полноценный режим игры через CLI для окружений без графического сервера.
- **Автоматическое тестирование**: Набор автоматических тестов CTest (`tests/test_core.cpp`).
- **Сохранение и загрузка**: Формат JSON v2 (`savegame.json`) с автосохранением каждые 60 секунд и при выходе.
- **Веб-интерфейс (`index.html`)**: Встроенная интерактивная страница-презентация проекта.

## 🛠️ Требования к окружению

- **ОС**: Windows 10 / 11 (Visual Studio 2022 MSVC x64)
- **Компилятор**: C++20 стандарт
- **CMake**: 3.20 или выше
- **Пакетный менеджер vcpkg**:
  - `sfml` (версия 3.x)
  - `nlohmann-json` (3.12.0+)

## 🚀 Сборка проекта

```powershell
# Перейти в директорию проекта
cd "D:\rust_ccop\copy_rust\v6.0 - GUI"

# Сгенерировать файлы сборки через CMake
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_TOOLCHAIN_FILE=D:/for_vv/vcpkg/scripts/buildsystems/vcpkg.cmake

# Скомпилировать проект в режиме Release
cmake --build build --config Release
```

## 🎮 Запуск

```powershell
# Графический режим (SFML 3)
.\build\Release\real_copy_rust.exe

# Консольный режим
.\build\Release\copy_rust_console.exe

# Запуск тестов
ctest --test-dir build -C Release --output-on-failure
```

## 🕹️ Управление (SFML GUI)

| Клавиша | Действие |
| :--- | :--- |
| `WASD` / Стрелки | Движение персонажа |
| `Shift` | Ускорение (бег, расходует энергию) |
| `Space` / `E` | Сбор ближайших ресурсов / атака |
| `ЛКМ` | Перемещение в точку / автоматический сбор / атака |
| `ПКМ` | Отмена автоматического действия |
| `1` – `4` | Быстрый выбор инструмента из хотбара |
| `Tab` | Переключение между инструментами |
| `C` | Меню крафта |
| `I` | Инвентарь персонажа |
| `M` | Карта острова |
| `H` | Окно справки |
| `F` | Употребить еду (ягоды) |
| `R` | Отдых у костра / Возрождение после смерти |
| `F1` | Переключение подсказок HUD |
| `F5` / `F9` | Быстрое сохранение / загрузка игры |
| `F11` | Переключение полноэкранного режима |
| `Колесо мыши` | Изменение масштаба камеры (зум) |
| `Esc` | Пауза / Закрыть окна |
