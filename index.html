Что тебя ждёт

Мир генерируется сам: деревья, рудные жилы, ягодные кусты и звери. День и ночь сменяются в реальном времени, а savegame.json пишется автоматически каждые 60 секунд и при выходе.

🧭 Остров у тебя под контролем

Иди клавишами или кликай мышью — персонаж сам дойдёт и соберёт всё рядом. Зум колесом, миникарта под M.

⛏️ Крафт и инструменты

Хотбар на 1–4, меню крафта на C, инвентарь на I. Каменный топор → железо → броня.

🔥 Ночь не застанет врасплох

Показатели жизни расходуются на каждое действие. Отдых у костра на R, перекус на F.

🧪 Ядро тестируется

Игровое ядро отделено от UI и гоняется автотестами CTest — см. tests/test_core.cpp.

Сборка из исходников

Нужны VS 2022 (MSVC x64), CMake 3.20+ и vcpkg с sfml 3.x и nlohmann-json.

# 1. Клонируем
git clone https://github.com/chelicpubg228-design/copy_rust_vibe_code.git
cd copy_rust_vibe_code

# 2. Генерируем сборку (vcpkg)
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_TOOLCHAIN_FILE=D:/for_vv/vcpkg/scripts/buildsystems/vcpkg.cmake

# 3. Собираем и запускаем
cmake --build build --config Release
.\build\Release\real_copy_rust.exe        # GUI
.\build\Release\copy_rust_console.exe     # CLI
ctest --test-dir build -C Release --output-on-failure  # тесты
